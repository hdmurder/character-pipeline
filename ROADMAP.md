# Roadmap

## Golem first

Repair and human-calibrate data checks. Freeze real-transcript judge calibration and held-out evaluation splits. Human-review source rights and original character documents. Run a numerical/fit smoke test before committing to training.

Fit a shared 4B SFT checkpoint, then compare DPO, KTO and continued SFT with matched budgets. Run the separate document-graft experiment with unrelated-document and direct-Instruct controls. Publish complete configuration, checkpoint lineage, permitted data and negative results.

Measure character continuity alongside evidence-backed belief revision and ordinary competence. Add activation monitoring and steering as controlled baselines, not claims that a character occupies one neuron. Test competing-finetune survival only after an initial behavioral signal.

## Many characters

Replicate the same pipeline with characters that differ in outlook, not merely vocabulary. Each folder supplies a bible, source manifest, training config and character-specific rubric. Keep shared evals and add held-out tasks that test each character's disposition without asking them who they are.

Only then compare an 8B-class and a 27B-class student. Pin exact matched Base/Instruct families first; do not transfer neuron indices across checkpoints. Report cost per accepted conversation and per completed fit.

## Multi-agent simulations

Place independently evaluated characters in shared environments with persistent state and explicit interaction rules. Track whether disagreement, diversity and individual continuity survive group incentives. Compare individual and collective rewards. Do not treat a simulated society as evidence of reliable real-world autonomy.

This is a later research direction, not a delivered simulator. Shared state must distinguish observed actions from invented narrative. Start with no external tools or live-world effects.
